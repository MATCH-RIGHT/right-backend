[[resources-sms]]
== SMS

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| VERIFICATION_CODE_SEND_SUCCESS
| 인증코드 전송 성공

| EQUAL_VERIFICATION_CODE_SUCCESS
| 인증코드 확인 성공

|===

==== 오류 코드  
[cols="1,3"]
|===
| Code | Description

| SMS_SEND_FAILED
| SMS 전송 실패

| INVALID_PHONE_NUMBER
| 올바르지 않은 전화번호 형식

| VERIFICATION_CODE_NOT_FOUND
| 인증코드가 존재하지 않음

| DIFFERENT_VERIFICATION_CODE
| 인증코드가 일치하지 않음

| VERIFICATION_CODE_EXPIRED
| 인증코드가 만료됨

|===
