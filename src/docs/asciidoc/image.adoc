[[resources-image]]
== Image

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| IMAGE_UPLOAD_SUCCESS
| 이미지 업로드 성공

| IMAGE_UPDATE_SUCCESS
| 이미지 업데이트 성공

| IMAGE_DELETE_SUCCESS
| 이미지 삭제 성공

| IMAGES_RETRIEVED
| 이미지 목록 조회 성공

|===

==== 오류 코드
[cols="1,3"]
|===
| Code | Description

| IMAGE_UPLOAD_FAILED
| 이미지 업로드 실패

| IMAGE_NOT_FOUND
| 이미지를 찾을 수 없음

| INVALID_IMAGE_FORMAT
| 올바르지 않은 이미지 형식

| IMAGE_SIZE_EXCEEDED
| 이미지 크기 초과

| S3_UPLOAD_FAILED
| S3 업로드 실패

| IMAGE_DELETE_FAILED
| 이미지 삭제 실패

|===
