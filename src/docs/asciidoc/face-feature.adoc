[[resources-face-feature]]
== Face Feature

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| FACE_FEATURE_UPLOAD_SUCCESS
| 얼굴 특징 업로드 성공

| FACE_FEATURES_RETRIEVED
| 얼굴 특징 조회 성공

| ALL_FACE_FEATURES_RETRIEVED
| 모든 얼굴 특징 조회 성공

|===

==== 오류 코드
[cols="1,3"]
|===
| Code | Description

| FACE_FEATURE_UPLOAD_FAILED
| 얼굴 특징 업로드 실패

| FACE_FEATURE_NOT_FOUND
| 얼굴 특징을 찾을 수 없음

| REKOGNITION_ERROR
| AWS Rekognition 오류

| INVALID_IMAGE_FOR_ANALYSIS
| 분석에 적합하지 않은 이미지

|===
