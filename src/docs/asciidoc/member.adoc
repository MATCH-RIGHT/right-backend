[[resources-member]]
== Member

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| SIGN_UP_SUCCESS
| 회원가입 성공

| AVAILABLE_ID
| 사용 가능한 아이디

| PROFILE_UPDATE_SUCCESS
| 프로필 수정 성공

| PASSWORD_CHANGE_SUCCESS
| 비밀번호 변경 성공

| PROFILE_RETRIEVED
| 프로필 조회 성공

| INTERESTS_RETRIEVED
| 관심사 목록 조회 성공

| LOCATIONS_RETRIEVED
| 지역 목록 조회 성공

|===

==== 오류 코드
[cols="1,3"]
|===
| Code | Description

| DUPLICATE_ID
| 중복된 아이디

| NULL_MEMBER
| 존재하지 않는 회원

| INVALID_ID_FORMAT
| 올바르지 않은 아이디 형식 (3-20자 영문/숫자)

| WEAK_PASSWORD
| 취약한 비밀번호 (8-24자, 영문/숫자/특수문자 포함 필요)

| EMPTY_PASSWORD
| 비밀번호가 비어있음

| INVALID_PHONE_NUMBER
| 올바르지 않은 전화번호 형식

| PROFILE_UPDATE_FAILED
| 프로필 업데이트 실패

|===
