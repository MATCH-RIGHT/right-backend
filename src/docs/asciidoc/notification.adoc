[[notification-api]]
= 알림(Notification) API

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| FCM_TOKEN_REGISTER_SUCCESS
| FCM 토큰 등록 성공

| FCM_STATUS_CHANGE_SUCCESS
| FCM 상태 변경 성공

| NOTIFICATIONS_RETRIEVED
| 알림 목록 조회 성공

| NOTIFICATION_READ_SUCCESS
| 알림 읽음 처리 성공

| FCM_STATUS_RETRIEVED
| FCM 상태 조회 성공

| UNREAD_COUNT_RETRIEVED
| 읽지 않은 알림 수 조회 성공

|===

==== 오류 코드
[cols="1,3"]
|===
| Code | Description

| FCM_MESSAGING_ERROR
| FCM 메시징 오류

| FCM_TOKEN_NOT_FOUND
| FCM 토큰을 찾을 수 없음

| NULL_NOTIFICATION
| 존재하지 않는 알림

| IS_NOT_OWNER
| 알림 소유자가 아님

| NOTIFICATION_SEND_FAILED
| 알림 전송 실패

|===
