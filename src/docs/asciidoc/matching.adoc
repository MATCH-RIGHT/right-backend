[[resources-matching]]
== Matching

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| MATCHING_EXECUTION_SUCCESS
| 매칭 실행 성공

| LIKE_SUCCESS  
| 좋아요 성공

| MATCHING_RESULTS_RETRIEVED
| 매칭 결과 조회 성공

|===

==== 오류 코드
[cols="1,3"]
|===
| Code | Description

| UNSUPPORTED_MATCHING_TYPE
| 지원하지 않는 매칭 타입

| INSUFFICIENT_MEMBERS
| 매칭할 회원이 부족함

| MATCHING_RESULT_NOT_FOUND
| 존재하지 않는 매칭 결과

| EXPIRED_MATCHING
| 만료된 매칭

| UNAUTHORIZED_USER
| 해당 매칭에 참여하지 않은 사용자

| DUPLICATE_LIKE_REQUEST
| 중복 좋아요 요청

| MATCHING_EXECUTION_FAILED
| 매칭 실행 실패

|===
