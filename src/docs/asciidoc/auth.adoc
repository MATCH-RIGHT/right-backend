[[resources-post]]
== Authentication

=== 응답 코드

==== 성공 코드
[cols="1,3"]
|===
| Code | Description

| LOGIN_SUCCESS
| 로그인 성공

| LOGOUT_SUCCESS
| 로그아웃 성공

| TOKEN_REISSUE_SUCCESS
| 토큰 재발급 성공

| WITHDRAW_SUCCESS
| 회원탈퇴 성공

|===

==== 오류 코드
[cols="1,3"]
|===
| Code | Description

| LOGIN_FAILED
| 로그인 실패 (아이디 또는 비밀번호 불일치)

| INVALID_TOKEN
| 유효하지 않은 토큰

| EXPIRED_TOKEN
| 만료된 토큰

| REFRESH_TOKEN_NOT_FOUND
| 리프레시 토큰을 찾을 수 없음

| INVALID_REFRESH_TOKEN
| 유효하지 않은 리프레시 토큰

| UNAUTHORIZED_ACCESS
| 인증되지 않은 접근

|===
